speaking model. /linter/

A model completes the document you started. This tool checks which slots of that document you left empty — heuristically, honestly, entirely in your browser. Nothing you paste leaves this page.

Usage notes

    Paste a prompt and lint it. Short factual questions legitimately need few slots — the linter scales its judgment to the size of the ask.

    Heuristic, not a model: it pattern-matches phrases from the book. A green slot can still be badly filled; a red slot can be fine for a simple ask. Judgment stays with you. From Speaking Model: A Practitioner's Dictionary · source
